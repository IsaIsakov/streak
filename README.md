# Наш огонёк v4

Старт отношений: 7 августа 2026.

## Railway
1. Загрузите эти три файла в корень проекта.
2. Для сохранения фото и истории между redeploy подключите Railway Volume к `/data`.
3. Redeploy.
4. Первый заход откроет создание пары: два имени и два PIN.

## Что умеет
- дни вместе не обнуляются;
- ежедневная отметка обоих продлевает «Искорку»;
- три состояния: грустит / ждёт / горит;
- никнеймы для обоих;
- загрузка фоновой фотографии прямо с телефона;
- общая приватная лента: записки, фото, рисунки;
- JSON для будущего виджета: `/api/widget`;
- все интерфейсные фразы на русском.

## Важно
Без Volume Railway может потерять загруженные фото и JSON-состояние при новом деплое. Сам сервер использует `/data`, если этот путь доступен.
